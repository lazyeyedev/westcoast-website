# WestCoast Construction & Consult website


```
index.html  about.html  services.html  projects.html  contact.html  404.html
robots.txt  sitemap.xml  site.webmanifest
assets/css/styles.css   assets/js/main.js
assets/img/    logo, logo-mark, photos, og-image
assets/icons/  favicon and app icons
```

## Before launch
1. Replace placeholder email `info@westcoastconstruction.co` (search all .html files and `assets/js` is not affected; the form email is the `data-email` attribute in contact.html).
2. Domain is set to https://westcoastconstruction.co in the HTML, robots.txt and sitemap.xml. Change it there if it ever moves (for example to a www address).
3. Swap illustrative photos in `assets/img/` for real project photography.
4. The contact form opens the visitor's email app. For a server-side form, connect Formspree, Netlify Forms or similar.
